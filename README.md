# Zolo Plugin SDK

[![CI](https://github.com/devzolo/zolo-plugin-sdk/actions/workflows/ci.yml/badge.svg)](https://github.com/devzolo/zolo-plugin-sdk/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/devzolo/zolo-plugin-sdk)](https://github.com/devzolo/zolo-plugin-sdk/releases)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

The public Rust SDK for building native plugins for the Zolo programming
language. It contains only the stable plugin boundary, procedural macros, and
the shared-allocation bridge required across dynamic-library boundaries. The
Zolo compiler itself is not part of this repository.

## Add the SDK

Until the crates are published on crates.io, depend on a release tag:

```toml
[dependencies]
zolo-plugin = { git = "https://github.com/devzolo/zolo-plugin-sdk.git", tag = "v0.1.1" }
```

Cargo records the exact commit behind the tag in `Cargo.lock`.

## Minimal plugin

```rust
use zolo_plugin::prelude::*;

fn hello(_args: &[PluginValue]) -> Result<PluginValue, PluginError> {
    Ok(PluginValue::String("hello from Rust".into()))
}

#[derive(Default)]
struct HelloPlugin;

impl ZoloPlugin for HelloPlugin {
    fn name(&self) -> &str {
        "hello"
    }

    fn version(&self) -> &str {
        "0.1.0"
    }

    fn register(&self, ctx: &mut PluginContext) {
        ctx.add_function(
            "hello",
            hello,
            FnSignature {
                params: vec![],
                returns: TypeHint::String,
            },
        );
    }
}

zolo_plugin::export_plugin!(HelloPlugin);
```

Build the plugin as a dynamic library:

```toml
[lib]
crate-type = ["cdylib", "rlib"]
```

Then point the Zolo loader at the output directory with `ZOLO_PLUGIN_DIR` and
import it using `use plugin hello`.

## Workspace crates

| Crate | Purpose |
| --- | --- |
| `zolo-plugin` | Plugin values, signatures, registry, loader, handles, and export ABI |
| `zolo-plugin-macros` | Procedural macros re-exported by the SDK |
| `zolo-alloc` | Shared host/plugin allocator bridge |
| `zolo-alloc-exports` | Linker configuration for allocator symbols exported by the host |

## Compatibility

Release `v0.1.0` implements Zolo plugin ABI **3**. The host and plugin ABI
versions must match; the loader rejects mismatches before invoking plugin
code. SDK releases before `1.0.0` may contain source-level breaking changes,
which will be called out in [CHANGELOG.md](CHANGELOG.md).

Dynamic plugins exchange owned strings and collections across the ABI. The
SDK installs the Zolo allocator shim in plugin libraries so both sides use the
same host-owned heap. Do not replace the global allocator generated by
`export_plugin!`.
